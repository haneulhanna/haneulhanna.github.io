# Ha-Neul (Hanna) Park — Engineering Portfolio

Minimal black-and-white, GitHub Pages-ready static portfolio.

## Publish on GitHub Pages

1. Upload the **contents of this folder** to the root of `haneulhanna.github.io`.
2. GitHub → Settings → Pages.
3. Choose `Deploy from a branch` → `main` → `/ (root)`.
4. Visit `https://haneulhanna.github.io`.

The CSS is embedded directly in `index.html`, so the live site does not depend on a separate stylesheet file.
