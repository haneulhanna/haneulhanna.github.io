# Hanna Park — Final Engineering Portfolio

Static HTML/CSS portfolio focused on embedded firmware, RTOS/kernel work, RTL/digital hardware, Embedded Linux, and low-level systems.

## Run locally

Open `index.html`, or from this folder run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000
